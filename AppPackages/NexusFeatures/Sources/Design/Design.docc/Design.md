# ``Design``

Design tokens for the Nexus UI. Views never hardcode a color literal, padding value, SF Symbol name, or user-facing string — they reference these namespaces, so the app's colors, spacing rhythm, iconography, and copy are each decided in one place. System-backed palette members resolve dynamically per appearance; brand and semantic accents are fixed values tuned to read in both.
